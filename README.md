This repository showcases my successful completion of the **SOC Fundamentals** course and documents the knowledge, skills, and achievements gained throughout the learning journey.

The course provided a strong foundation in Security Operations Center (SOC) concepts, security monitoring, log management, SIEM, EDR, and SOAR while developing the mindset required for a SOC Analyst role.

---

## 📖 About the Course

The **SOC Fundamentals** course introduces the core responsibilities of a Security Operations Center and prepares learners for entry-level SOC Analyst roles by covering:

* Security Operations Center (SOC)
* SOC Types & Roles
* SOC Analyst Responsibilities
* SIEM Fundamentals
* Log Management
* Endpoint Detection & Response (EDR)
* Security Orchestration, Automation and Response (SOAR)

---

## 🎯 Learning Outcomes

After completing this course, I gained knowledge of:

* Understanding the purpose and workflow of a Security Operations Center.
* Different SOC models and analyst roles.
* Security monitoring and alert triage.
* Log collection, storage, and analysis.
* SIEM architecture and investigation workflow.
* Endpoint Detection and Response (EDR).
* Security Orchestration, Automation, and Response (SOAR).
* Incident detection and response fundamentals.
